Implemented instruction classes

R-type: ADD, SUB, AND, OR, XOR. I-type: ADDI. Memory: LW, SW. Branch: BEQ, BNE, according to the implemented control and ALU decode paths.

This is a custom RISC-style subset. Do not label it a complete RV32I implementation.

04 / control contracts

Next-PC, writeback and branch logic

Next PC selector

next_pc = branch_taken
        ? branch_target
        : pc_plus4;

Implemented by next_pc_selector. Branch target and branch_taken originate from branch_unit.

Writeback selector

writeback_data =
  MEM_WB_MemToReg
  ? MEM_WB_ReadData
  : MEM_WB_ALUResult;

The register-file write port receives writeback_data, MEM_WB_rd and MEM_WB_RegWrite.

Branch decision

BEQ: rs1_data == rs2_data
BNE: rs1_data != rs2_data

target = ID_EX_PC + immediate

Branch operands are forwarded_A and forwarded_B. A taken branch redirects fetch and flushes IF/ID and ID/EX.

05 / sequential state

Pipeline register payload map

IF / ID

PC[31:0] · Instruction[31:0]

Enable: IF_ID_Write. Flush: branch_taken. Reset and flush clear output payload.

ID / EX

PC · rs1_data · rs2_data · immediate · rs1 · rs2 · rd · funct3 · funct7

RegWrite · ALUSrc · MemRead · MemWrite · MemToReg · Branch · ALUOp

Enable tied high. Flush: ID_EX_Flush OR branch_taken.

EX / MEM

PC · ALU_Result · forwarded_B · rd · Zero · RegWrite · MemRead · MemWrite · MemToReg

Enable tied high; flush tied low.

MEM / WB

ReadData · ALUResult · rd · RegWrite · MemToReg

Enable tied high; captures memory data and ALU result for writeback selection.

06 / dependency resolution

Forwarding and hazard detection

Forwarding priority

Forward codeSourceCondition
10EX/MEM ALU resultEX_MEM_RegWrite && EX_MEM_rd != 0 && match
01writeback_dataMEM_WB_RegWrite && MEM_WB_rd != 0 && match, if no EX/MEM match

In processor.v, EX/MEM is encoded as 2'b10 and MEM/WB as 2'b01 for both source operands.

Load-use interlock equation

ID_EX_MemRead
&& (ID_EX_rd != 0)
&& ((ID_EX_rd == hazard_rs1)
 || (ID_EX_rd == hazard_rs2))

PCWrite     = 0
IF_ID_Write = 0
ID_EX_Flush = 1

processor.v qualifies hazard_rs1/rs2 by opcode so unused source fields are forced to register zero.
